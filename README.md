# Somos Luz — Landing Page

Landing page e loja da **Somos Luz** (velas vegetais artesanais).

- Instagram: [@somosluzvela](https://www.instagram.com/somosluzvela/)
- Pedidos finalizados via WhatsApp com resumo do carrinho.

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- React Router (páginas: início, produto, coleção, carrinho, checkout)

## Desenvolvimento

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Lint & tipos

```sh
npm run lint
npx tsc --noEmit -p tsconfig.app.json
```
